# Proposal

## Why

Про самообслуживание доступов почти никто не знает. Кнопка Request Access есть только на странице топика, а пользователь без доступа к сообщениям туда не идёт: вкладки Data у него нет, и страница молча открывает Configs. Пункт Access в меню ни о чём не говорит, письма о релизах не читают. Идея пришла от коллег из инфраструктуры (онбординг-тур).

## What Changes

- Маскот Альфа-Капитала Гаврюша: появляется в правом нижнем углу в нужный момент и говорит с пользователем через облачко
- При первом входе после релиза Гаврюша предлагает показать, как получить доступ, и запускает тур
- Тур по реальному интерфейсу раздела Access (без демо-песочницы и моков): меню Access, My Requests, запрос на префикс, кнопка Request Access на топике; шаги про одобрение — только владельцам префиксов и суперадминам
- На странице топика без права читать сообщения вместо молчаливого перехода на Configs — вкладка Data с плашкой «Нет доступа к сообщениям» и кнопкой Request Access; Гаврюша один раз за сессию подсказывает то же самое
- Признаки «тур пройден» и «больше не показывать» хранятся в браузере (localStorage) с версией тура; новая версия тура покажется заново
- Два эндпоинта для UI: является ли пользователь согласующим и может ли он читать сообщения конкретного топика
- Новая зависимость фронтенда `react-joyride`
- Всё работает только при включённом access management; при выключенном поведение равно оригиналу

## Capabilities

### New Capabilities

- `access-onboarding`: маскот, тур по разделу Access, подсказка на странице топика без доступа к сообщениям, правила показа

### Modified Capabilities

- `topic-access-requests`: добавляются эндпоинты сведений о правах текущего пользователя (согласующий, чтение сообщений топика)

## Impact

- Фронтенд: новые компоненты форка (маскот, тур, плашка), картинки `client/src/images/mascot/`, точечные правки `Topic.jsx` (вкладка Data и плашка), метки целей тура в `Sidebar.jsx` и `AccessManagement.jsx`, зависимость `react-joyride`
- Бэкенд: два GET-эндпоинта в контроллере access management, тесты
- БД и конфигурация не меняются
- Зависит от TASK-8: `Topic.jsx` берётся в версии после вливания upstream
