# acl-view Specification

## Purpose
Корректная работа страниц списка и деталей Kafka ACL для принципалов с любыми символами Unicode (например, кириллица в LDAP-принципалах): принципал кодируется в URL как Base64 от UTF-8-байтов вместо Latin1-only `btoa`/`atob`.

## Requirements

### Requirement: Кодирование принципала в URL
Страница списка ACL SHALL формировать ссылку на детали вида `/ui/{cluster}/acls/{principalEncoded}`, где `principalEncoded` — стандартный Base64 от UTF-8-байтов строки принципала. Построение списка MUST NOT завершаться ошибкой для принципалов с символами вне Latin1.

#### Scenario: Принципал с кириллицей
- **WHEN** в кластере есть ACL с принципалом `User:CN=Тестов Тест,OU=Users,DC=example,DC=com`
- **THEN** страница `/ui/{cluster}/acls` отображается без ошибки `InvalidCharacterError`, а ссылка на детали содержит Base64 UTF-8-байтов принципала

### Requirement: Декодирование принципала на странице деталей
Страница деталей ACL MUST декодировать `principalEncoded` из URL как Base64 → UTF-8 и показывать исходный принципал в заголовке `Acl: <principal>`. То же закодированное значение SHALL передаваться в API `/api/{cluster}/acls/{principalEncoded}`; backend декодирует его в JVM-кодировке по умолчанию, поэтому среда выполнения MUST использовать UTF-8 (в образе задано `-Dfile.encoding=UTF-8`).

#### Scenario: Открытие деталей не-Latin1 принципала
- **WHEN** пользователь переходит из списка ACL к принципалу с кириллицей
- **THEN** заголовок страницы показывает принципал без искажений, а вкладки Topics, Groups, Clusters и Transactional Ids загружают ACL этого принципала

### Requirement: Совместимость ссылок для ASCII-принципалов
Для принципалов из ASCII-символов закодированное значение MUST совпадать побайтно с результатом прежнего `btoa`, чтобы ранее сохранённые ссылки на детали ACL продолжали работать.

#### Scenario: Старая ссылка на ASCII-принципал
- **WHEN** пользователь открывает сохранённую ранее ссылку `/ui/{cluster}/acls/VXNlcjphbGljZQ==` (принципал `User:alice`)
- **THEN** открывается страница деталей ACL принципала `User:alice`
